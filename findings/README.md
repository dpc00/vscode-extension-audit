# Findings not filed

Complete issue texts for defects found in the audit that have **not** been posted to the extension's own issue tracker. Each file is one finding, written as the issue would have been filed: title, body, evidence. Extension authors are welcome to look for their own extension here.

File name: `<extension id>-<short-topic>.md`. First line of each file: `Status: not filed` (changed to `Filed: <link>` or `Dropped: <reason>` when the owner of this repository decides).

Reports that were filed are listed in `ISSUES.tsv`.
