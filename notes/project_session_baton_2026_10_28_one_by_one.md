## Update 2026-11-12: reconnecting vscode-mcp after a restart (opencode)
- After `reload_window`, or any extension-host restart, the SAME tools come back on their own once port 9560 answers: poll `get_help` until `pid` changes (the first call can hit ECONNREFUSED).
- A restart that brings NEW tools is different. opencode keeps the tool list it first fetched, so a tool the server is already serving still answers "Unknown tool". Fix without a file edit or harness restart: `opencode api post '/api/experimental/mcp/vscode-mcp/connect?location%5Bdirectory%5D=C%3A%5CUsers%5Cdonal%5Cprojects%5Csublime-commander'` (location-scoped; a wrong cwd answers McpServerNotFound), then call the tool. Seen 2026-11-12 when 0.8.4's `self_test` was unknown after the reload to 1.146.0, then answered 12/12 immediately after the connect.
